## Дополнительные заметки для докладчика

**Общая рекомендация по формулировкам.** Для каждой возможности разделяйте три разные даты: (1) первая реализация в каком-либо браузере, (2) `Baseline newly available` — есть во всех основных браузерах, (3) `Baseline widely available` — прошло 30 месяцев, можно считать безопасной для массового продакшена. Определения статусов — [web.dev: Baseline](https://web.dev/baseline).

**Что на август 2026 нельзя называть «широко доступным» (widely available):** Popover API (widely ожидается 27 июля 2027, [web-features](https://web-platform-dx.github.io/web-features-explorer/features/popover/)), `@scope` (newly available с декабря 2025, [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/@scope)), customizable `<select>` (вообще не Baseline, [MDN](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select)), Temporal в браузерах (нет Safari, [Can I Use](https://caniuse.com/temporal)), Prompt API (возражения Mozilla и WebKit, [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Prompt_API)), WebMCP (origin trial, [Chrome](https://developer.chrome.com/blog/ai-webmcp-origin-trial)), A2UI (v0.8 preview, [GitHub](https://github.com/google/A2UI)).

**Аккуратные слайд-безопасные даты (цитируемые):** Flexbox widely available 2018-03-30; Grid widely available 2020-04-17; JS modules widely available 2020-11-09; fetch widely available 2019-09-27; `<dialog>` widely available 2024-09-14; popover newly available 2025-01-27 — все из [web-features explorer](https://web-platform-dx.github.io/web-features-explorer/widely-available/).

**Терминологическая осторожность.** «Community Group Report» (WebMCP), «open project / public preview» (A2UI), «Stage 4 proposal» (Temporal) и «W3C Recommendation» — это четыре разных уровня зрелости; в докладе о legacy-платформе смешивание их — самая заметная фактическая уязвимость.
