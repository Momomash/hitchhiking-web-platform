# Slidev-фрагменты для доклада «Самое большое легаси, с которым мы работаем — веб-платформа»

Готовые к вставке блоки для Slidev-слайдов. Оба графика — самостоятельные SVG-файлы без внешних зависимостей (шрифты и все объекты растеризованы/встроены как пути и текстовые узлы средствами matplotlib, CDN и JS не требуются). Просто скопируйте нужный SVG-файл в директорию слайдов (например, `./assets/`) и используйте один из вариантов вставки ниже.

---

## Визуализация 1 — Таймлайн механизмов координации

**Файл:** `web-platform-coordination-timeline.svg` (и `.png` как запасной вариант растрового изображения)

### Вариант A — простая вставка через `<img>`

```md
---
layout: image-right
image: ./assets/web-platform-coordination-timeline.svg
---

# Совместимость стала измеримой дисциплиной

Веб-платформа не менялась по единому плану — она обрастала
механизмами координации: WHATWG (2004), Test262 (2011),
WPT (2012–2017), Interop (2022), Baseline (2023).
```

```md
layout: center

<img src="./assets/web-platform-coordination-timeline.svg" class="w-full mt-4" />
```

### Настройка цвета/шрифта под тему презентации

SVG использует шрифт `DejaVu Sans` (встроен как контуры — заменять не нужно, но при желании
можно перегенерировать `chart1_timeline.py` с другим `font.family`) и палитру Nexus:
фон `#F7F6F2`, текст `#28251D`, приглушённый текст `#7A7974`. Если тема доклада тёмная —
проще всего положить SVG на светлую подложку-карточку (`background: #F7F6F2; border-radius: 12px; padding: 24px;`),
чем перекрашивать сам файл.

```html
<div style="background:#F7F6F2; border-radius: 16px; padding: 24px;">
  <img src="./assets/web-platform-coordination-timeline.svg" style="width:100%" />
</div>
```

## Визуализация 2 — Разрыв «workaround → нативный стандарт»

**Файл:** `workaround-to-standard-lag.svg` (и `.png` как запасной вариант)

### Вариант A — простая вставка

```md
---
layout: image-right
image: ./assets/workaround-to-standard-lag.svg
---

# От библиотеки до платформы — сколько лет проходит

Медиана по 11 измеренным кейсам — 9,1 года. От 2,6 года
(Container Queries) до 14,5 лет (`<dialog>`).
```

### Вариант B — с постепенным появлением строк (клики)

Так как это единый растрово-векторный график из Python, "построчного" reveal без пересборки
не будет — Slidev показывает SVG целиком. Если нужен пошаговый reveal по кейсам, самый
дешёвый путь — показать этот SVG целиком на **последнем** шаге, а для промежуточных шагов
использовать текстовые буллеты с теми же цифрами (ниже) и в конце "раскрыть" полную картинку:

```md
---
layout: default
---

# Разрыв между экосистемой и платформой

<div v-click="1">Container Queries: ResizeObserver (2020) → Baseline (2023) — **2,6 года**</div>
<div v-click="2">Flexbox: 960 Grid System (2009) → Baseline (2015) — **5,8 года**</div>
<div v-click="3">CSS Grid: Bootstrap grid (2009) → Baseline (2017) — **7,8 года**</div>
<div v-click="4">Fetch API: jQuery.ajax (2006) → Baseline (2017) — **10,6 года**</div>
<div v-click="5">&lt;dialog&gt;: jQuery UI Dialog (2007) → Baseline (2022) — **14,5 года**</div>

<img v-click="6" src="./assets/workaround-to-standard-lag.svg" class="w-full mt-4" />
```

### Настройка цвета/шрифта под тему презентации

Цвета: workaround — терракотовый `#A84B2F`, нативная возможность — тёмная бирюза `#20808D`,
линии-коннекторы — светло-серый `#BAB9B4`. Это часть чарт-палитры Nexus — при желании
перекрасить под фирменный стиль доклада достаточно поменять `WORKAROUND_C` / `NATIVE_C`
в `chart2_lag.py` и перегенерировать.

## Общие рекомендации по использованию на сцене

1. Оба графика — самодостаточные SVG (нет внешних скриптов/шрифтов/CDN), поэтому безопасно
   встраивать offline, в PDF-экспорт Slidev и в PowerPoint-совместимые сборки.
2. Каждый график сопровождён встроенной внизу методологической сноской — не убирайте её
   при кадрировании: это ответ на "а откуда цифры?", который может прозвучать из зала.
3. Если экран маленький (проектор с низким разрешением) — используйте `.png` (200 dpi)
   вместо `.svg`, чтобы не терять читаемость мелкого текста сносок.
4. Обе визуализации используют один и тот же временной диапазон оси X (условно 1995–2028) —
   если показываете их подряд, зрителю будет проще сопоставить масштаб.
